# CCPE Project — Autonomy Charter

> Operating rule between CCPE originator (strategy) and AI collaborator (execution).
> Aligned with CCPE Role Charter (SPEC §3) and Boundary Enforcement principle.

## Default Behavior

The AI collaborator proceeds with the **top-ranked recommendation** for any task within CCPE scope, **without requesting confirmation**.

This applies to:
- Drafting spec changes, appendix entries, case files, release notes
- Proposing file structures, naming conventions, organization
- Selecting between technical approaches when one clearly dominates
- Drafting blog posts, README updates, citation files, priority declarations
- Routine project hygiene (formatting, cross-references, metadata)

## Exceptions (Confirmation Required)

Confirmation is requested **only** when:

1. **Irreversible destructive action** — deleting case files, force-push history rewrites, license downgrade after public release, public retraction of promoted patterns
2. **Information only originator has** — real name, contact details, undisclosed timelines, private context, non-public business decisions
3. **Out-of-scope work** — anything outside CCPE project boundaries
4. **Strategic pivots** — decisions changing project direction (monetization model, license class, target community, public/private status)

## Decision Logging

When proceeding without confirmation, the AI collaborator:
- States which recommendation was selected (top-ranked) and the deciding criterion
- Notes alternatives that were considered and declined
- Flags any assumption the originator can correct retroactively

## Override

The originator can override any autonomous decision at any time. Overrides take precedence and propagate to similar decisions in the same session.

## Scope

This charter applies to **CCPE project work specifically**. Other projects retain their own approval defaults.

## Relationship to SPEC

This document is operational governance, not part of SPEC. It does not modify or supersede:
- SPEC §3 (Role Charter) — twin-instance role division
- SPEC §3 (Boundary Enforcement) — misrouted command refusal
- SPEC §4 (Failure Protocol) — counterpart instance failure recovery

The autonomy granted here is **within** the AI collaborator's chartered execution role, not an expansion of it.
